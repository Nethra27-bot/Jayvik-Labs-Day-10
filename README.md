# Day 10 – Linux Files & Permissions 🐧



## 📌 Project Overview
This assignment focuses on Linux file management, directory operations, file permissions, ownership, and important Linux filesystem directories.

## 🎯 Learning Objectives
- Understand Linux directories and file management.
- Learn basic file-handling commands.
- Understand Linux file permissions (Read, Write, Execute).
- Learn user, group, and others permissions.
- Understand `chmod` and numeric permission modes.
- Explore important directories such as `/etc`, `/home`, and `/var`.
- Identify security risks caused by incorrect permissions.

## 💻 Commands Practiced

| Command | Description |
|---|---|
| `mkdir` | Creates a directory |
| `touch` | Creates an empty file |
| `cat` | Displays file contents |
| `cp` | Copies files |
| `mv` | Moves or renames files |
| `rm` | Removes files |
| `ls -l` | Displays detailed file information |
| `chmod` | Changes file permissions |

## 🔐 Linux File Permissions

- **r (Read):** Permission to read.
- **w (Write):** Permission to modify.
- **x (Execute):** Permission to execute or access.

**Permission Examples:**
- `chmod 755` – Owner: Read, Write, Execute | Group/Others: Read, Execute.
- `chmod 644` – Owner: Read, Write | Group/Others: Read only.

## 📂 Important Linux Directories
- `/etc` – System configuration files.
- `/home` – User personal directories.
- `/var` – Logs and variable system data.
- `/` – Root directory.
